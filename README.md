# NestMint

Personal financial coach: tracks bills, loans, installments and daily spending, shows monthly net savings, and helps reach savings goals.

## Status

Planning complete. Phase 1 (Core Budget Tracking, MVP) not started.

## Documentation

Product docs (analysis, requirements, PRD, roadmap) live in Notion under **NestMint**.

## Planned stack

- Frontend: React, TypeScript, Tailwind CSS
- Backend: Node.js, NestJS, TypeScript
- Database: PostgreSQL
- Auth: JWT
- API: REST with OpenAPI
